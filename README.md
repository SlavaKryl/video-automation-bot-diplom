# video-automation-bot-diplom
В бота загружается короткое или не очень видео. Бот обрезает тишину (в идеале пропуски в речи и слова паразиты) транскрибирует. Потом готовит рился для ютуба, ВК, рутуба, и текстовый пост в ВК, Дзен, ТГ, Макс. Потом заправшивает у пользователя подтверждение и публикует в выбранные пользователем каналы
